# First visual exploration — archived

Preserved before refining the user's shortlist on 2026-10-16. These source snapshots
record the initial ten themes and their styling. They are not loaded or shipped in
the active viewer.

Retired from comparison and further iteration: Copper Canyon, Midnight Arcade,
Moss & Mechanism, Sakura Atelier, Abyssal Station, Ember Forge, Pocket Factory.
The original timber workshop is also no longer a comparison choice. Lunar Assembly,
Frostline Works and Blueprint Bureau continue in `presentation/variants.js`.

The retained source is a restoration reference, not a separate supported app.
