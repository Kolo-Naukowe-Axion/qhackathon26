Schedule objective uses the actual last completion. QUBO energy uses the measured makespan register, which can be larger. Across six cases: QAOA 60/60 optimal schedules and 57/60 exact encoded minima; SA 60/60 of both. No quantum advantage established.

The compute budget matters.

QAOA: 128 exact simulated expectation/CVaR evaluations + 8,192 Born samples. Uniform: 8,192 samples. Annealing: 32 replicas × 256 proposals. These are unequal costs. CP-SAT certifies the same input independently. Preparation enumerates the one-hot sector classically.

03 / FROM SHOP FLOOR TO QUBO

One choice per operation.
Every conflict accounted for.

A bit chooses an operation, machine, qualified worker and start time. A separate one-hot register bounds completion.

E = J + P Σg(Σi∈g xᵢ − 1)²
+ P Σ(i,j)∈conflicts nᵢⱼ xᵢxⱼ

J = (H+1) × weighted terminal tardiness + encoded makespan. The nonnegative objective is bounded by B; choosing P = B+1 makes every infeasible state worse than every feasible state.
