# Axion branding

- `axion-logo.png` is an unchanged copy of the actual Axion site's `public/assets/images/logo2.png`, supplied through the user's `axion2.0` project. It replaces the provisional asterisk mark.
- Axion's header uses this mark with the `AXION` wordmark in Space Grotesk. Its UI uses Manrope. These font families are retained here and served locally.
- Manrope and Space Grotesk were downloaded from Google's official font distribution. Their SIL Open Font Licenses are included alongside the font files.
- The Axion logo is a brand asset; the project's MIT source license does not relicense third-party marks or fonts.
